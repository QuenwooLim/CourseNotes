## 🧩 课程项目

### 第一次大作业

[`project_1/`](project_1/) 包含三个任务：

- 使用简单神经网络完成 Fashion-MNIST 和 CIFAR-10 图像分类
- 使用预训练 ResNet-50 完成图像分类
- 使用预训练 ResNet-50 完成目标检测

项目中包含 [`question1.py`](project_1/question1.py)、[`question2.py`](project_1/question2.py)、[`question3.py`](project_1/question3.py) 以及实验报告。

### 第二次大作业

[`project_2/`](project_2/) 以聚类算法为主题，包含：

- 手动实现 K-Means
- 手动实现 K-Means++ 初始化
- 聚类质量评估和可视化实验

入口文件包括 [`problem1.py`](project_2/problem1.py) 和 [`problem2.py`](project_2/problem2.py)。

### 第三次大作业

[`project_3/`](project_3/) 包含：

- GSM8K 数据集上的 LLM 数学推理评测
- ScienceQA 数据集上的多模态科学问答
- Qwen2.5 模型调用、量化、Prompt 构造和结果分析
