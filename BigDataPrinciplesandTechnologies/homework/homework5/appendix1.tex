\chapter{实验代码}

\section{项目文件清单}
下列为仓库中与实验直接相关的主要文件及其简要说明：
\begin{itemize}
	\item \textbf{code/stock.csv}: 已上传的原始股票历史数据（CSV，含日期与收盘价）。
	\item \textbf{code/utils.py}: 数据加载、CSV 容错处理、滑动窗口构造与 \texttt{stock\_data.npz} 保存加载函数。
	\item \textbf{code/arima\_model.py}: ARIMA 拟合与显式预测。
	\item \textbf{code/lstm\_numpy.py}: 手写 LSTM 前向、BPTT 反向传播、优化器（SGD/Adam）、梯度裁剪、递归与多步输出实现。
	\item \textbf{code/main.py}: 实验流水线入口，负责参数解析、数据准备、模型训练/预测、指标计算与绘图。
	\item \textbf{code/plots.py}, \textbf{code/metrics.py}: 绘图函数与 MAE/RMSE 实现。
\end{itemize}
