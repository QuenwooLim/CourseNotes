## CUDA矩阵乘法朴素实现

**原理**：每个GPU线程计算输出矩阵的一个元素，通过遍历输入矩阵的行和列进行乘加运算，最终将结果写入全局内存

**问题**：
- 延迟高和带宽受限：全局内存访问需数百周期、每个线程均要读写全局内存
- 带宽浪费：A（B）的同一行（列）被多个线程重复读取

```
A         B
|         |
|    ×    |   =   C
|         |
```

**基本步骤**：
1. 从全局内存读取A的一行
2. 从全局内存读取B的一列
3. 计算一次乘累加得到C的一个元素，并写回全局内存

**访存延迟**：几百个时钟周期

---

## 分块加载：用共享内存缓存数据

**原理**：将频繁访问的全局内存数据批量加载到速度更快的共享内存中。通过分块计算实现数据重用，减少全局内存访问次数

**分块思想**：
- 将大矩阵划分为数据块，每个线程块负责处理一个数据块
- 数据重用：一个数据块被加载到共享内存后，该线程块内的所有线程都可以重复读取它，实现"一次加载，多次计算"

```
A         B         C
|         |         |
|    ×    |   =     |
|         |         |
```

**基本步骤**：
1. 读取A矩阵一个block到共享内存
2. 读取B矩阵一个block到共享内存
3. 利用共享内存数据进行乘加运算
4. 写回一个block到全局内存

**访存延迟**：几十个时钟周期

---

## 寄存器分块：提升计算密度

**原理**：在共享内存分块的基础上，让每个线程利用寄存器缓存数据，避免对共享内存的重复访问，进一步提升计算访存比

**分块计算**：
- 每个线程内部处理一个tile，提高计算密度
- 寄存器缓存：线程将频繁使用的数据存储在寄存器中，避免重复加载共享内存

**基本步骤**：
1. 从共享内存A加载tile_size×1的A块到寄存器
2. 从共享内存B加载1×tile_size的B块到寄存器
3. 利用寄存器进行多次乘加，累加结果留在寄存器中
4. 遍历完tile后，将寄存器累加的一整组结果写回全局内存

**访存延迟**：几个时钟周期

### 性能对比

| 优化方式 | 访存次数 | 乘加次数 | 计算访存比 | 提升 |
|---------|---------|---------|-----------|------|
| 无寄存器优化 | 4+4次 | 4次 | 0.5 | - |
| 使用寄存器优化 | 4+4次 | 16次 | 2.0 | 4倍 |

**提示**：
- Tile Size决定单个线程工作量/寄存器个数
- Block Size决定并行度/共享内存的分块大小
