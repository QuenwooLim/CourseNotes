## 实验思考

### (1) 在配置静态路由前, PC1 ping PC2, 分析此时为何不通?
在配置静态路由之前, PC1 ping PC2 是不通的, 这个结果符合网络基本原理, 详细的通信失败过程及原因分析如下:

首先, PC1 (IP: 192.168.1.11) 会判断目标 IP 地址 192.168.3.22 是否与自己在同一个网段。通过子网掩码 255.255.255.0 计算后, PC1 发现目标地址与自己不属于同一网络。因此, PC1 不会在本地网络中广播 ARP 请求, 而是会将这个数据包发送给自己的默认网关, 也就是路由器 R1 的接口地址 192.168.1.1。

接着, 数据包成功到达路由器 R1。R1 在收到数据包后, 会查找自己的路由表, 试图找到一条能够匹配目标地址 192.168.3.22 的路由条目。然而, 在配置静态路由之前, R1 的路由表中只存在通过其激活接口自动生成的直连路由 (即 192.168.1.0/24 和 192.168.2.0/24)。R1 在路由表中找不到任何关于如何去往 192.168.3.0/24 网段的路径信息。

最终, 由于无法找到匹配的路由条目, R1 不知道下一步该将数据包转发给谁。根据路由器的转发原则, 对于目标地址不可达的数据包, 路由器会将其丢弃。同时, R1 通常会向发送方 PC1 发送一个 ICMP (Internet Control Message Protocol) 的“目标主机不可达”错误消息。因此, PC1 上最终显示的便是“请求超时”或“目标主机无法访问”, 因此通信失败。这也就是为什么, 在配置静态路由前, PC1 ping PC2 不通。

### (2) 要实现 PC1 和 PC2 的通信, 本实验共配置了几条静态路由? 分别是什么? 其含义是什么?
要实现 PC1 与 PC2 之间完整的双向通信, 本实验共配置了两条静态路由, 分别位于路由器 R1 和 R2 上。这两条路由缺一不可, 共同构成了数据包的“去程”和“返程”路径。

1.  **第一条 (去程路由), 配置在 R1 上:**
    *   **命令:** `[R1] ip route-static 192.168.3.0 24 192.168.2.2`
    *   **含义:** 这条命令是在为从 PC1 到 PC2 的数据包“指路”。它告诉路由器 R1: “如果收到一个目标地址属于 192.168.3.0/24 网段 (即 PC2 所在的网段) 的数据包, 那么应该将这个数据包转发给下一跳邻居, 其 IP 地址为 192.168.2.2。” 这里的 192.168.2.2 正是路由器 R2 的接口地址。

2.  **第二条 (返程路由), 配置在 R2 上:**
    *   **命令:** `[R2] ip route-static 192.168.1.0 24 192.168.2.1`
    *   **含义:** 这条命令是在为从 PC2 返回给 PC1 的响应数据包“指路”。它告诉路由器 R2: “如果收到一个目标地址属于 192.168.1.0/24 网段 (即 PC1 所在的网段) 的数据包, 那么应该将它转发给下一跳邻居, 其 IP 地址为 192.168.2.1。” 这里的 192.168.2.1 正是路由器 R1 的接口地址。

总结来说, 第一条静态路由解决了数据包“如何去”的问题, 而第二条静态路由解决了数据包“如何回”的问题。只有同时配置了这两条路由, 才能构成一个完整的、可达的通信闭环, 从而实现 PC1 与 PC2 之间的双向互通。

### (3) 如果路由器中存在去往同一网段的多条路由信息, 路由器会采用哪一个进行转发?
如果路由器中存在多条去往同一目标网段的路由信息, 路由器会遵循一套严谨的、分优先级的决策流程来选择最优的路由进行转发。这个流程通常被称为“最长匹配原则”和“路由选择算法”, 主要包括以下三个步骤:

1.  **最长前缀匹配原则:**
    这是路由器进行路由选择的第一原则, 也是最高优先级的规则。当路由表中有多条路由都可以匹配一个目标 IP 地址时, 路由器会选择子网掩码最长 (即前缀长度最长, / 后面的数字最大) 的那一条路由。因为掩码越长, 代表路由指向的网络范围越精确、越具体。例如, 如果同时存在去往 192.168.0.0/16 和 192.168.1.0/24 的路由, 那么一个去往 192.168.1.10 的数据包, 将会优先匹配 /24 这条更精确的路由。

2.  **比较管理距离/优先级:**
    在前缀长度相同的情况下, 路由器会比较这些路由的来源可靠性, 即比较它们的管理距离 (AD) 或优先级 (Preference)。这个数值越小, 代表路由来源越可靠, 优先级越高。例如, 华为设备中, 直连路由 (Direct) 的优先级为 0, 静态路由 (Static) 的优先级为 60, OSPF 路由的优先级为 10。如果同时存在一条静态路由和一条 OSPF 路由都指向同一个 /24 网段, 路由器会优先选择优先级更高的 OSPF 路由。

3.  **比较度量值:**
    如果多条路由的前缀长度和优先级都完全相同 (通常意味着它们来自于同一种路由协议), 路由器最后会比较它们的度量值 (Metric 或 Cost)。度量值代表了到达目标网络的“成本”或“距离”, 这个值越小, 代表路径越优。例如, 在 RIP 协议中, Metric 是跳数; 在 OSPF 协议中, Cost 是基于链路带宽计算得出的开销。路由器会选择 Metric 值最小的那条路径进行数据转发。如果此时 Metric 值也相同, 则可以实现负载均衡 (Load Balancing), 让数据包在多条路径上分担流量。
