## 🧪 网络实验

[`Lab/`](Lab/) 按实验主题组织了实验指导、实验记录、源材料、拓扑图片、代码和报告文件：

| 实验目录 | 内容 |
|:---|:---|
| [实验基础](Lab/Lab1_Basic/) | 网络实验基础材料 |
| [网络编程](Lab/Lab2_NetworkPrograme/) | 套接字编程、TCP/UDP 实验及实验报告材料 |
| [静态路由](Lab/Lab3_StaticRoute/) | 静态路由配置与实验记录 |
| [访问控制](Lab/Lab4_AccessControl/) | ACL 原理、配置和实验材料 |
| [VLAN](Lab/Lab5_VLAN/) | VLAN 原理、交换机配置和跨交换机实验 |
| [OSPF](Lab/Lab6_OSPF/) | OSPF 实验指导、命令资料和实验报告 |
| [生成树协议](Lab/Lab7_SpanningTree/) | 生成树原理、快速生成树配置和实验报告 |
| [期末实验考核](Lab/LabFinal_Exam/) | 期末实验题目、源文件、报告和配套代码 |

实验目录通常按照 `source/`、`lab/`、`report/` 和 `images/` 分类保存原始指导材料、实验过程文件、报告和配图。
