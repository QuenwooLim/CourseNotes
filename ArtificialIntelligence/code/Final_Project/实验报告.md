## 一、实验概述
出土竹简是了解我国古代历史、思想、制度、文化等的重要资料。但由于多种因素影响，竹简在埋藏过程中常常散乱断裂，给解读工作带来了较大的挑战。缀合就是将这些竹简残片依据形状、文字内容、断口痕迹等信息重新拼接起来。只有成功缀合，才能恢复竹简原本的顺序和内容的完整性，从而获取准确的历史信息。然而，缀合工作常常需要人类专家人工完成，工作量较大。因此，使用人工智能技术实现竹简残片的缀合技术研究正日益成为研究的焦点。

本项目以《里耶秦简（二）》的已缀合（yizhuihe）和未缀合（weizhuihe）竹简图片为数据集，综合运用图像处理、深度学习（孪生神经网络）等技术，自动实现竹简的缀合与分类。实验流程包括数据筛选、特征提取、模型训练、自动缀合、可视化与评估等环节。

### 1.1 实验内容与目标

1. **数据预处理与筛选**  
   - 依据图片命名规则和形状特征，自动筛选出完整简和残断简。
   - 对未缀合数据集（weizhuihe）自动识别完整简，放宽标准，只要形状大致符合"下端削尖、上端弧形、四边平整"即可判为完整简，并将其保存到新文件夹。
2. **特征提取与数据增强**  
   - 对每根竹简图片提取轮廓特征（形状、边缘、宽度等）和纹理特征（LBP、GLCM等）。
   - 对训练样本进行数据增强（旋转、翻转、亮度变化等）。
3. **模型设计与训练**  
   - 采用孪生神经网络（Siamese Network），输入为竹简对，输出为相似度分数。
   - 在yizhuihe所有缀合组上构建正负样本对，训练网络判别竹简对的可缀合性。
4. **自动缀合与可视化**  
   - 用训练好的模型在未缀合数据集上自动寻找可缀合对。
   - 对缀合结果进行可视化展示，支持单组和批量可视化。
5. **评估与分析**  
   - 采用准确率、召回率等指标评估模型效果。
   - 对实验结果进行可视化和定性分析。

## 二、方法与模型设计

### 2.1 数据处理与特征工程

- **数据筛选**  
  利用OpenCV对每张图片进行轮廓检测，依据面积、长宽比、边缘平整度等指标自动判别完整简。放宽完整简标准，提升实际检测效果，避免误判。

- **特征提取**  
  - 形状特征：面积、周长、凸包、边界矩形、长宽比、边缘直线度等。
  - 纹理特征：局部二值模式（LBP）、灰度共生矩阵（GLCM）等。

- **数据增强**  
  对正负样本对进行旋转、翻转、亮度变化等增强，提升模型泛化能力。

- **数据集划分**  
  - 训练集：yizhuihe所有缀合组的竹简对。
  - 测试集：weizhuihe未缀合数据。

### 2.2 模型框架

- **孪生神经网络结构**  
  - 输入：两张竹简图片，分别经过共享权重的特征提取网络（包含形状和纹理分支）。
  - 特征融合：将两张图片的特征向量拼接，计算欧氏距离/余弦相似度。
  - 损失函数：对比损失（Contrastive Loss），鼓励可缀合对距离小、不可缀合对距离大。

- **训练流程**  
  - 正样本：同一缀合组内相邻竹简对。
  - 负样本：不同组随机竹简对。
  - 训练时动态增强样本，提升鲁棒性。

- **自动缀合流程**  
  - 对未缀合残断简两两组合，计算相似度，低于阈值则判为可缀合对。

### 5.2 孪生网络设计

#### 5.2.1 网络结构
```python
class SiameseBambooNetwork(nn.Module):
    def __init__(self, contour_dim=5, texture_dim=18):
        super(SiameseBambooNetwork, self).__init__()
        
        # 轮廓特征处理网络
        self.contour_encoder = nn.Sequential(
            nn.Linear(contour_dim, 64),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(64, 32),
            nn.ReLU()
        )
        
        # 纹理特征处理网络
        self.texture_encoder = nn.Sequential(
            nn.Linear(texture_dim, 128),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(64, 32),
            nn.ReLU()
        )
        
        # 融合网络
        self.fusion_network = nn.Sequential(
            nn.Linear(128, 64),  # 64(轮廓) + 64(纹理) = 128
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, 1),
            nn.Sigmoid()
        )
```

#### 5.2.2 损失函数
采用对比损失函数（Contrastive Loss），更适合孪生网络：

```python
class ContrastiveLoss(nn.Module):
    def __init__(self, margin=1.0):
        super(ContrastiveLoss, self).__init__()
        self.margin = margin
        
    def forward(self, similarity, label):
        # 正样本：相似度应该高
        # 负样本：相似度应该低
        pos_loss = (1 - label) * torch.pow(similarity, 2)
        neg_loss = label * torch.pow(torch.clamp(self.margin - similarity, min=0.0), 2)
        loss = pos_loss + neg_loss
        return torch.mean(loss)
```

### 5.3 设计思路

#### 5.3.1 多特征融合
考虑到竹简缀合需要综合考虑形状、纹理等多个特征，我们设计了多特征融合的网络结构：
- **轮廓特征**：反映竹简的整体形状和断口特征
- **纹理特征**：反映竹简表面的纹理和墨迹特征
- **特征融合**：通过神经网络自动学习最优的特征组合方式

#### 5.3.2 端到端学习
整个系统采用端到端的学习方式，从原始图像到最终的缀合决策，所有参数都通过反向传播自动优化。

### 6.2 创新点

#### 6.2.1 多模态特征融合
创新性地将轮廓特征和纹理特征结合，更好地捕捉竹简的几何和纹理信息：

```python
def forward(self, x1_contour, x1_texture, adj1, x2_contour, x2_texture, adj2):
    # 处理轮廓特征
    contour_feat1 = self.contour_encoder(x1_contour)
    contour_feat2 = self.contour_encoder(x2_contour)
    
    # 处理纹理特征
    texture_feat1 = self.texture_encoder(x1_texture)
    texture_feat2 = self.texture_encoder(x2_texture)
    
    # 特征融合
    combined_feat1 = torch.cat([contour_feat1, texture_feat1], dim=1)
    combined_feat2 = torch.cat([contour_feat2, texture_feat2], dim=1)
    
    # 计算相似度
    similarity = self.fusion_network(combined_feat1, combined_feat2)
    return similarity
```

## 八、重述探索、优化、创新过程

本项目的开发与实验过程，经历了从初步实现到多轮优化和创新的完整科研闭环。以下详细梳理了主要的探索、优化与创新实践，突出真实的工程思考与技术迭代。

### 8.1 需求驱动与初步实现

项目伊始，面对竹简缀合这一实际需求，首先调研了相关领域的人工与自动化方法，明确了“自动检测、自动缀合、缀合可视化”三大核心目标。初步实现阶段，采用了传统图像处理方法进行竹简轮廓检测和简单的特征比对，但很快发现仅靠几何特征难以应对复杂的残片形态和纹理变化，缀合准确率有限。

### 8.2 多特征融合与孪生网络引入

为提升模型的判别能力，我们探索了多模态特征融合的思路，将形状特征（如面积、长宽比、边缘平整度等）与纹理特征（如 LBP、GLCM）结合，设计了特征提取与融合流程。经过多轮实验，最终采用了孪生神经网络架构，分别处理两根竹简的多种特征，并通过端到端训练自动学习最优的缀合判别方式。这一创新极大提升了模型的泛化能力和缀合准确率。

### 8.3 智能分类与标准调整

在实际数据处理中，发现“完整简”与“残断简”的区分对后续缀合效果影响极大。最初的完整简判定标准较为严格，导致部分实际可用的竹简被误判为残断。为此，我们反复分析样本，放宽了完整简的判定标准，只要大致形状符合即可。通过调整 `is_complete_bamboo` 函数，极大提升了完整简的识别率，保证了训练数据的丰富性和代表性。

### 8.4 可视化模块的多轮优化

可视化是本系统的重要环节，既便于结果展示，也方便人工复核。最初的可视化模块存在图片模糊、缩放失真等问题。我们多次优化拼接逻辑，确保可视化图片采用原图高质量拼接，并根据竹简正反面情况智能适配展示方式。最终实现了批量可视化、单组可视化、正反面智能拼接等功能，极大提升了系统的实用性和美观性。

### 8.5 批量处理与自动化流程

随着数据量的增加，手动处理和验证变得低效。我们开发了批量分类、批量缀合、批量可视化等自动化脚本，实现了从数据筛选、特征提取、模型训练到结果输出的全流程自动化，大幅提升了实验效率和系统可扩展性。

### 8.6 评估与持续改进

在实验过程中，我们不断通过交叉验证、人工复核、可视化对比等方式评估系统效果。针对模型在部分极端残片上的误判，我们尝试引入更多先验知识（如断口特征、墨迹分布等），并为后续研究预留了接口。每一次评估和反馈都推动了系统的持续优化。

### 8.7 创新总结

- **多模态特征融合**：首次将形状与纹理特征深度融合于竹简缀合任务，显著提升了模型表现。
