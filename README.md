## 📚 项目简介

本仓库用于整理大学阶段的课程学习资料，覆盖基础编程、数据结构、人工智能、机器学习、计算机系统与数学基础等方向。

课程内容遵循中山大学计算机学院计算机科学与技术专业的23级本科生培养体系，仓库中保存相关专业课程的：

- 💻 实验代码与课程项目
- 📝 作业、实验报告与课程笔记
- 📖 教材、参考资料与复习材料
- 🧠 算法、系统与人工智能相关实践

> 这是一个以学习记录和知识沉淀为主的开源仓库。如果其中的资料或代码对你有帮助，欢迎点亮 ⭐ Star，让更多同学发现它。
