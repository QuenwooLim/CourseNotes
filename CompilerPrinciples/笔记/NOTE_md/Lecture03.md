# 正则表达式 (Page 16/54)

- **正则表达式：构造性定义**
  - 基础：
    - ε 是正则表达式；L(ε) = {ε}。
    - a 是正则表达式，如果 a ∈ Σ；L(a) = {a}。
  - 归纳：如果 r 和 s 是正则表达式，
    - r | s 是正则表达式；L(r | s) = L(r) ∪ L(s)。
    - r s 是正则表达式；L(r s) = L(r) L(s)。
    - r* 是正则表达式；L(r*) = (L(r))*。
    - (r) 是正则表达式；L((r)) = L(r)。
  - 扩展：
    - r+ = r, r* = r* r
    - r? = r | ε
    - [ace] = a | c | e, [A–Z] = A | B | ... | Z 

# 正则表达式语言 (Page 17/54)

- **正则表达式：一种语言**
  - 语法

    - a(a | b)*
  - 语义
    - {aab, abb}
    - {a, aa, ab, aaa, aab, aba, abb, ...}
- **语言是解决问题的替代方法。**

# 字母表：词法 vs. 语法 (Page 19/54)

- **扫描器和解析器都基于字母表 Σ。**
- **但 Σ 的含义（元素）完全不同。**
  - 扫描器：Σ 中的元素是源程序中的字符。
    - ASCII, EBCDIC, Unicode, ...
  - 解析器：Σ 中的元素是由扫描器生成和传递的词法单元。
 
# 正则表达式的代数定律 (Page 20/54)

- r | s = s | r
- r | (s | t) = (r | s) | t
- r | r = r
- r(st) = (rs)t
- r(s | t) = rs | rt
- (s | t)r = sr | tr
- rε = εr = r
- r\*r\* = r\*
- r\* = ε | r | rr | ...
- (r\*)\* = r\*
- rr\* = r\*r
- (r\* | s\*)\* = (r\*s\*)\*
- (r\*s\*)\* = (r | s)\*
- (rs)\*r = r(sr)\*
- (r | s)\* = (r\*s)\*r\*

**讨论：两个正则表达式等价意味着什么？**

# 第3类文法 (Page 27/54)

- **右线性（正则）文法**
  - A → aB 或 A → a，其中 A, B ∈ N ∧ a ∈ Σ U{ε}。
- **左线性文法**
  - A → Ba 或 A → a，其中 A, B ∈ N ∧ a ∈ Σ U{ε}。
- **扩展形式**
  - 右线性（正则）文法
    - A → αB 或 A → α，其中 A, B ∈ N ∧ α ∈ Σ*。
  - 左线性文法
    - A → Bα 或 A → α，其中 A, B ∈ N ∧ α ∈ Σ*。

# 形式化定义 (Page 29/54)

- **有限自动机是一个5元组：M = (Σ, S, Δ, s₀, F)，其中**
  - Σ 是输入字母表。
  - S ∩ Σ = ∅ 是有限状态集。
  - Δ 是转换函数。
  - s₀ ∈ S 是开始（初始）状态。
  - F ⊆ S 是接受（终止）状态集。
- **DFA、NFA和ε-NFA仅在以下方面不同**
  - 对于DFA，δ: S × Σ → S
  - 对于NFA，δ: S × Σ → 2ˢ
  - 对于ε-NFA，δ: S × (Σ ∪ {ε}) → 2ˢ
 
# 有限自动机定义的语言 (Page 30/54)

- **转换函数的重载**
  - 对于任何 a ∈ Σ, s ∈ S 和 ω ∈ Σ*,
    - δ(s, ε) = s
    - δ(s, ωa) = δ(δ(s, ω), a)
- **给定有限自动机 M，**
  - L(M) = {ω | ω ∈ Σ* ∧ ∃s ∈ F. δ(s₀, ω) = s}

# 计算ε闭包 (Page 42/54)

- **令 ε-closure({0}) = {0} = A，然后**
  - δ(A, 1) = ε-closure({1}) = {1, 2} = B
  - δ(B, 0) = ε-closure({3}) = {3, 4, 5, 6, 8, 11} = C
  - δ(C, 0) = ε-closure({9}) = {5, 6, 8, 9, 10, 11} = D
  - δ(C, 1) = ε-closure({7}) = {5, 6, 7, 8, 10, 11} = E
  - δ(D, 0) = ε-closure({9}) = D
  - δ(D, 1) = ε-closure({7}) = E
  - δ(E, 0) = ε-closure({9}) = D
  - δ(E, 1) = ε-closure({7}) = E

# 6. 正则语言的限制 (Page 46/54)

  - 不能用正则文法生成
