# 复习 (Page 5/32)

- **给定以下文法**
  ```
  E  → T E'
  E' → + T E' | ε
  T  → F T'
  T' → * F T' | ε
  F  → ( E )  | n
  ```
- **我们有**
  - $\text{FIRST}(F) = \text{FIRST}(T) = \text{FIRST}(E) = \{(, n\}$
  - $\text{FIRST}(T') = \{*, \varepsilon\}$
  - $\text{FIRST}(E') = \{+, \varepsilon\}$
  - $\text{FOLLOW}(E) = \text{FOLLOW}(E') = \{), \$\}$
  - $\text{FOLLOW}(T) = \text{FOLLOW}(T') = \{+, ), \$\}$
  - $\text{FOLLOW}(F) = \{+, *, ), \$\}$

# 语法分析表的构造 (Page 7/32)

- **算法：对于每个产生式 $A \to \alpha$**
  - 对于每个 $a \in \text{FIRST}(\alpha) \cap \Sigma$，将 $A \to \alpha$ 添加到 $M[A, a]$
  - 如果 $\varepsilon \in \text{FIRST}(\alpha)$，对于每个 $b \in \text{FOLLOW}(A)$，将 $A \to \alpha$ 添加到 $M[A, b]$
    - **注意**：$b$ 可能是 $ 符号，表示输入词法单元的结束
- **讨论：语法分析表中的冲突**
  - 单个条目是否可能包含多个产生式？
  - 这意味着什么？

# 预测分析控制器 (Page 14/32)

```java
initialize();
while(!stack.top().equals(new Symbol('$'))){
  top = stack.top();
  if(top instanceof Terminal){ // 匹配终结符
    stack.pop();
    match(top);
  } else{ // 推导非终结符
    if(table[top, lookahead] is X → Y1Y2...Yk){
      output(X → Y1Y2...Yk);
      stack.pop();
      stack.push(Yk, Yk-1, ..., Y1); // Y1在顶部
    } else error(); // 语法分析表中的空条目
  }
}
if(lookahead.equals(new Symbol('$'))) accept();
else error();
```

# 3. LL(1)语法分析中的错误恢复 (Page 24/32)

- **语法分析器在错误情况下应该做什么？**
  - 给出错误信息
    - 尽可能有意义
  - 从错误情况中恢复
    - 能够继续使用剩余输入进行语法分析

# LL(1)语法分析中的错误 (Page 25/32)

- **三种类型的错误**
  - **终结符不匹配**
    - 栈顶是终结符，但与向前看符号不匹配
  - **[栈顶, 向前看] = 空**
    - 没有产生式候选
  - **栈为空但输入未结束**
    - 栈为空，但输入字符串未结束

# 带同步的语法分析表 (Page 26/32)

| 非终结符 | n | + | * | ( | ) | $ |
|----------|---|---|---|---|---|---|
| E | T E' | | | T E' | synch | synch |
| E' | | + T E' | | | ε | ε |
| T | F T' | synch | | F T' | synch | synch |
| T' | | ε | * F T' | | ε | ε |
| F | n | synch | synch | ( E ) | synch | synch |

$\text{FOLLOW}(E) = \text{FOLLOW}(E') = \{), \$\}$  
$\text{FOLLOW}(T) = \text{FOLLOW}(T') = \{+, ), \$\}$  
$\text{FOLLOW}(F) = \{+, *, ), \$\}$  

弹出栈顶（较少）  
跳过向前看（较多）

# 带错误恢复的语法分析 (Page 27/32)

- **错误恢复策略**
  - 如果 [栈顶, 向前看] = 空，则
    - 跳过向前看，即前移输入并保持栈不变
  - 如果 [栈顶, 向前看] = synch，则
    - 跳过栈顶，即弹出栈并保持输入不变
  - 如果 栈顶 ≠ 向前看，则
    - 跳过栈顶，即弹出栈并保持输入不变

# 错误恢复技术 (Page 29/32)

- **恐慌模式错误恢复**
  - 跳过输入直到找到同步符号
- **短语级错误恢复**
  - 为每个空条目分配特定的错误例程
- **错误产生式**
  - 适用于常见错误但不是所有错误
- **全局修正**
  - 全局分析输入以找到错误
  - 昂贵且不实用
