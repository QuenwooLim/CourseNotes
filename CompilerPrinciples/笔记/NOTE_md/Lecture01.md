# BNF示例 (Page 22/61)

```
identifier ::= letter{ letter | digit}
letter ::= A | B|...| Z | a | b|...| z
digit ::= 0 | 1|...| 9
```

```
integer ::= [ symbol] unsigned
unsigned ::= digit{ digit}
symbol ::= + | -
digit ::= 0 | 1|...| 9
```

```
for_stmt ::= for loop_var := init direction final do stmt
loop_var ::= int_var
int_var ::= var_id
var_id ::= identifier
init ::= expr
final ::= expr
direction ::= to | downto
```

---

# 更多BNF示例 (Page 23/61)

**规则：**

```
bexpr ::= bexpr or bterm | bterm
bterm ::= bterm and bfactor | bfactor
bfactor ::= not bfactor | ( bexpr) | true | false
```

**实例：**
- true and false or(not true)
- false or true and not false
- true and false and(not false and(true or false))

# 编译器的结构 (Page 37/61)

```
字符流
    ↓
扫描器（Scanner）
    ↓  字符流（Token Stream）
解析器（Parser）
    ↓ -- 解析树（Parse Tree）----
语义分析器（Semantic Analyzer）  ｜
    ↓ -- 解析树（Parse Tree）----
中间代码生成器（Int. Code Generator）
    ↓ -- 中间代码（Intermediate Code）--
优化器（Optimizer）                    ｜
    ↓ -- 中间代码（Intermediate Code）--
代码生成器（Code Generator）
    ↓
目标代码
```

**前端**
- Lexical 语法定义：正则表达式、线性文法、有限自动机
- Syntax 语法定义：BNF
- 语义定义：类型系统、其他规则、非声明式动作

# 编译示例 (Page 40/61)

- `position= initial+ rate* 60`

**扫描器**
- Token stream: `<id,1><=><id,2><+><id,3><*><60>`

**解析器和语义分析器**

Parse tree:
```
    =
   / \
 id1  +
     / \
   id2  *
       / \
     id3 60
```

# 编译示例（续） (Page 41/61)

**中间代码生成器**
- `t1 = int2float(60)`
- `t2 = id3 * t1`
- `t3 = id2 + t2`
- `id1 = t3`

**代码优化器**
- `t1 = id3 * 60.0`
- `id1 = id2 + t1`

**代码生成器**
- `LDF R2, id3`
- `MULF R2, R2,#60.0`
- `LDF R1, id2`
- `ADDF R1, R1, R2`
- `STF id1, R1`
