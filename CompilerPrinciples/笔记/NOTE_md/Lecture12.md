# 支配者 (Page 28/63)

- **符号**
  - m DOM n 表示 m 是 n 的支配者
  - D(n) 是 n 的所有支配者的集合
    - **D(n) = {m | m DOM n}**
- **属性**
  - 入口是循环中所有节点的支配者
  - 二元关系 DOM 是偏序关系
    - 自反性、传递性和反对称性

---

# 计算 D(n) 的算法 (Page 29/63)

- **输入：流图 G = (N, E, n₀)**
  - N = 节点集合；E = 边集合；n₀ = 入口
- **算法**
  ```
  1. D(n₀) = {n₀};
  2. foreach(n ∈ N - {n₀}) D(n) = N;
  3. changed = true;
  4. while(changed){
  5.   changed = false;
  6.   foreach(n ∈ N - {n₀}){
  7.     newd = {n} ∪ (∩p∈PRE(n) D(p));
  8.     if(D(n) ≠ newd){
  9.       D(n) = newd; changed = true;
  10.    }
  11.  }
  12.}
  ```
  **PRE = 前驱节点**

# 回边和自然循环 (Page 31/63)

- **回边**
  - a → b 是回边如果 a → b ∈ E ∧ b DOM a
- **自然循环**
  - 由回边 a → b 定义的自然循环 = {b} ∪ {不经过 b 就能到达 a 的节点}

# 通过回边查找循环 (Page 33/63)

- **输入：回边 n → d**
- **算法：**
  ```
  1. void insert(Node m){
  2.   if(m ∉ loop){// d 不会被压入
  3.     loop = loop ∪ {m};
  4.     stack.push(m)
  5.   }
  6. }
  7. void main(){
  8.   Stack stack = new Stack();
  9.   loop = {d};// PRE(d) 不会被添加
  10.  insert(n);
  11.  while(stack.notEmpty()){
  12.    m = stack.pop();
  13.    foreach(p ∈ PRE(m)) insert(p)
  14.  }
  15.}
  ```

# 循环优化：代码移动 (Page 37/63)

- **代码移动的目标**
  - 循环头节点的前驱节点之后
- **什么代码可以移动？**
  对于指令 x = y op z，
  1. 它是循环不变操作
     - y 和 z 的所有可能定义都在循环外部，包括常量，或者（递归地）
     - 由循环不变值定义
  2. 循环中没有其他语句定义 x
  3. 循环中对 x 的所有使用都由它定义

# 循环优化：降低强度和消除归纳变量 (Page 38/63)

- **基本归纳变量**
  - i = i ± C
    - 循环中对 i 的唯一赋值
    - C 是循环不变的
- **归纳变量族**
  - j = C₁ * i ± C₂
    - C₁ 和 C₂ 都是循环不变的
- **动机**
  - 用族中的某个 j 替换 i
    - 可以移除 j 的乘法
    - 然后可以消除 i
  - 对索引变量特别有效

---

# 全局信息在哪里需要？ (Page 48/63)

- **局部优化**
  - 如果变量从未被使用，对变量的赋值可以被移除
- **循环优化：代码移动**
  - 根据变量的定义确定循环不变操作
  - 代码移动要求操作是循环中的唯一定义
  - 代码移动还要求定义的变量在循环出口处不活跃
- **循环优化：归纳变量消除**
  - 如果归纳变量在循环外部未被使用，可以被移除
- **代码生成**
  - 关于出口处活跃性的信息有助于寄存器利用

---

# 需要什么全局信息？ (Page 49/63)

- **定义**
  - 语句中 R 值的所有赋值（源）
- **使用**
  - 语句中 L 值的所有可能使用
- **活跃性**
  - 在语句之后，变量是否会作为 R 值被引用？

# 基本概念 (Page 50/63)

- **流图中的点（语句之间）**
  - 两个相邻语句之间
  - 第一个语句之前和最后一个语句之后
- **变量 x 的定义（语句）**
  - 可能给 x 赋值的语句
  - L 值
- **变量 x 的使用（语句）**
  - 将 x 作为操作数引用的语句
  - R 值

# 基本概念（续） (Page 51/63)

- **定义 d 到达点 p**
  - 存在从 d 之后的点到 p 的路径，使得 d 在路径上不被"杀死"
  - 当我们在 p 之后立即使用 x 时，x 的值可能由 d 确定

# Ud-链 与 Du-链 (Page 52/63)

- **Ud-链：变量 x 在使用语句 s 中的使用-定义链**
  - 可以到达 s 的 x 的定义集合
  - 用于查找循环不变量
  - 也用于全局常量折叠
- **Du-链：变量 x 在定义语句 s 中的定义-使用链**
  - 可以从 s 到达的 x 的使用集合
  - 用于循环优化中消除归纳变量
  - 也用于查找归纳变量族

---

# 到达定义分析 (Page 53/63)

- **前向数据流方程**
  ```
  out[B] = (in[B] - kill[B]) ∪ gen[B]
  in[B] = ∪p∈PRE(B) out[p]
  ```

- in[B]：B 入口之前的 ud-链
- out[B]：B 出口之后的 ud-链
- gen[B]：B 中可以到达 B 出口的所有定义
- kill[B]：被 B 杀死的 B 外部的所有定义

# Ud-链的构造 (Page 54/63)

- **输入：gen[] 和 kill[]；输出：in[] 和 out[]**
- **算法**
  ```
  for(int i = 1; i <= n; i++){ // 初始化
    in[Bi] = ∅;
    out[Bi] = gen[Bi];
  }
  changed = true;
  while(changed){ // 迭代
    changed = false;
    for(i = 1; i <= n; i++){
      newIn = ∪p∈PRE[Bi] out[p];
      if(newIn ≠ in[Bi]){
        changed = true;
        in[Bi] = newIn;
        out[Bi] = (in[Bi] - kill[Bi]) ∪ gen[Bi];
      }
    }
  }
  ```

# 一个示例：(3) Ud-链的构造 (Page 57/63)

- **用 in[B] 计算 ud-链**
  - 如果 s.x 在 B 中有定义在 s 之前，s.x 的 ud-链是单元素（最接近 s 的定义）
  - 否则，s.x 的 ud-链是 in[B] 中 x 的所有定义
- **结果 ud-链**
  - 变量 i 在定义 d2：{d1}
  - 变量 j 在定义 d4：{d2, d4, d5} // d3 是 i 的定义，不是 j
  - 变量 j 在定义 d5：{d4}
  - 变量 i 在定义 d6：{d3} // d4 和 d5 是 j 的定义，不是 i
  - 变量 j 在定义 d7：{d4, d5}

# 基于 Ud-链的全局常量传播和折叠 (Page 58/63)

```
changed = true;
while(changed){
  changed = false;
  foreach(语句[S: x = ...]){
    foreach(操作数 S.y){ // 常量传播
      if(S.y.ud-链只有一个 i 且 i 是[y = CONST]){
        用 CONST 替换所有 S.y;
        changed = true;
      }
    }
    if(S 有操作符且每个操作数都是 CONST){// 折叠
      let C = 常量操作的结果;
      用[x = C]替换 S;
      changed = true;
    }
  }
}
```

# 更多数据流方程：可用表达式 (Page 59/63)

- **前向数据流方程**
  ```
  out[B] = (in[B] - E_kill[B]) ∪ E_gen[B]
  in[B] = if(B == ENTRY, ∅, ∩p∈PRE(B) out[p])
  ```
- **in[B]：B 之前的可用表达式**
- **out[B]：B 之后的可用表达式**
- **E_gen[B]：B 生成的表达式**
- **E_kill[B]：B 杀死的表达式**
- **动机**
  - 在 s 处可用的表达式 E = X op Y 是从入口点到 s 的 E 的最后一次求值，且在 E 的定义之后没有对 X 和 Y 的重新定义
  - 用途：全局公共表达式消除

# 更多数据流方程：活跃性分析 (Page 60/63)

- **后向数据流方程**
  ```
  in[B] = (out[B] - def[B]) ∪ use[B]
  out[B] = ∪s∈SUCC(B) in[s]
  ```
- **in[B]：B 之前的活跃变量**
- **out[B]：B 之后的活跃变量**
- **use[B]：B 生成的活跃变量**
- **def[B]：B 杀死的活跃变量**

**SUCC = 后继节点**
