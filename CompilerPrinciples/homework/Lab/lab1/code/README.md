# 个人所得税计算器命令行操作说明

## 启动方法

1. 进入 `code/` 目录：
   ```sh
   cd code
   ```
2. 编译所有 Java 文件：
   ```sh
   javac *.java
   ```
3. 运行主程序：
   ```sh
   java PersonalTaxApp
   ```

## 菜单说明

- 1. 计算个税：输入本月工资，系统自动计算应缴纳个人所得税。
- 2. 设置起征点：可自定义起征点数值。
- 3. 设置税率：依次输入5档税率（如0.05表示5%）。
- 4. 查看当前配置：显示当前起征点和各档税率。
- 0. 退出：安全退出程序。

## 操作提示

- 所有输入均有中文提示，输入错误会有友好提示并可重新输入。
- 支持浮点数输入，税率输入需为0~1之间的小数。
- 程序界面简洁，菜单清晰，适合新手快速上手。
