## ✏️ 课程作业

[homework](homework/) 目录包含三次课程作业。每次作业目录均保留了对应的说明文档，部分作业同时包含 Python 源代码、运行环境配置、流程图或提交材料。

### 第一次作业：分治策略——书本分配问题

- [作业报告与算法说明](homework/homework1/README.md)
- [主程序](homework/homework1/main.py)
- [流程图生成程序](homework/homework1/create_flowchart.py)

### 第二次作业：最长重复非重叠子字符串

- [作业报告与算法说明](homework/homework2/README.md)
