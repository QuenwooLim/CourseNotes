# 课程项目说明

## 基于深度神经网络的中文短新闻主题分类

### 一、项目目标

本项目要求学生在一个中小规模中文自然语言处理数据集上，独立完成数据预处理、神经网络设计、模型训练、实验评测与报告撰写。项目重点考查学生是否能够熟练运用 RNN + Attention 或 Transformer 相关思想设计深度神经网络，并通过规范实验分析模型性能。

学生需要完成一个中文短文本主题分类任务：给定一条新闻标题或短新闻文本，预测其所属主题类别。学生可自行选择基于循环神经网络与注意力机制的模型，或基于 Transformer 的模型；本说明不提供具体网络结构、层数、隐藏维度、注意力形式、优化参数等实现建议，这些内容由学生根据课程知识和实验结果自行探索。

### 二、项目任务

任务输入为一条中文新闻标题或短新闻文本，任务输出为该文本所属的新闻主题类别。学生需要完成从原始数据到最终实验报告的完整流程。

- 下载并读取 TNEWS 中文新闻短文本分类数据集。
- 完成必要的数据清洗、文本切分、编码和数据划分。
- 自行设计并训练一个 RNN + Attention 或 Transformer 模型。
- 在验证集上进行模型选择，并在测试集上报告最终结果。
- 使用 Accuracy、Macro-F1、混淆矩阵等指标完成实验评测。
- 撰写实验报告，说明方法、训练过程、实验结果、错误分析和心得体会。

### 三、数据集说明与下载

推荐数据集为 TNEWS 今日头条中文新闻短文本分类数据集，来源于 CLUE 中文语言理解测评基准。该数据集包含 15 个新闻主题类别，训练集约 53,360 条，验证集 10,000 条，公开测试集 10,000 条。

为避免网络访问问题，本课程推荐优先使用 CLUE 官方压缩包。若 Hugging Face 无法访问，不影响完成作业，学生可使用 CLUE 官方压缩包或 OpenDataLab 入口获取同一数据集。

| 下载方式 | 说明 |
| ---- | --- |
| [CLUE 官方压缩包](https://storage.googleapis.com/cluebenchmark/tasks/tnews_public.zip)  | 经测试可下载；压缩包约 4.88 MB，包含 train.json、dev.json、test.json、test1.0.json、labels.json、README.txt。 |
| [备用下载一：Hugging Face](https://huggingface.co/datasets/clue/clue/tree/main/tnews) | 提供 train、validation、test 的 parquet 文件；适合网络可访问 Hugging Face 的同学使用。 |
| [备用下载二：OpenDataLab](https://opendatalab.org.cn/OpenDataLab/TNews) | 国内数据平台入口；当 Hugging Face 不可用时可作为备用来源。 |

CLUE 官方压缩包中的主要文件说明如下：

| 文件名 | 用途 | 字段说明 |
| --- | --- | --- |
| train.json | 训练数据 | 每行为一个 JSON 样本，包含 label、label_desc、sentence、keywords。 |
| dev.json | 带标签验证数据 | 字段与 train.json 基本一致，可作为课程最终测试集使用。 |
| test.json | 公开测试数据 | 通常只包含 id、sentence、keywords，不含 label；不建议作为课程最终评分数据。 |
| labels.json | 类别映射文件 | 包含 label 与 label_desc 的对应关系。 |
| README.txt | 数据说明 | 包含数据集更新说明。 |

课程实验划分方式：使用 train.json 中的数据按固定随机种子划分为训练集和验证集，例如 90% 用于训练、10% 用于验证；使用 dev.json 作为课程最终测试集（因为官方的test set是没有label的）。学生必须在报告中说明随机种子、划分比例和各部分样本数量。

注意：数据文件为 UTF-8 编码。若在 Windows 终端中直接查看出现乱码，应在程序中显式使用 UTF-8 读取。

### 四、必要的数据预处理要求

- **数据读取与字段整理**：读取 sentence 和 label 字段，去除空文本、重复样本和非法标签样本，统计各类别样本数量。
- **文本清洗**：处理多余空格、异常字符、不可见字符、全角半角符号不一致等问题。是否保留数字、英文、标点符号，由学生根据实验设计自行决定，并在报告中说明理由。
- **文本切分**：可采用中文字符级切分、词级分词或子词切分。若使用词级分词，可使用 jieba 等工具；若使用子词方法，可使用 SentencePiece、BPE 或 WordPiece 等工具。
- **词表或编码处理**：若模型需要词表，应只使用训练集构建词表，并说明低频词、未知词、长度截断和填充方式。不得把验证集或测试集标签信息用于词表筛选、特征选择或模型调参。
- **复现实验设置**：自行划分数据时必须固定随机种子，并记录数据划分方式。

### 五、模型与训练要求

学生需自行设计并训练一个深度神经网络模型，模型主体应体现以下两类思想之一：

- RNN + Attention
- Transformer

学生可以进行多种模型、训练策略或文本表示方式的对比实验，但不得直接调用已经完成分类任务的现成模型作为主要结果。允许使用公开词向量、分词工具或基础深度学习框架，但需在报告中说明来源和使用方式。

训练过程应包括训练集训练、验证集选择模型、测试集最终评估。学生需要记录关键训练过程，例如损失变化、验证集指标变化、过拟合现象、训练时间或模型规模等。

### 六、实验评价标准

本项目主要采用以下评价指标。最终成绩不只依据测试集分数排名，更重视实验设计是否合理、评测是否规范、分析是否深入。

- **Accuracy**：衡量模型整体分类正确率。Accuracy = 正确预测样本数 / 总样本数。
- **Macro-F1**：先分别计算每个类别的 F1 值，再对所有类别求平均。该指标能够更好反映模型在各类别上的均衡表现，避免只关注大类别。
- **混淆矩阵**：学生应给出混淆矩阵或类别级分析，观察模型容易混淆的新闻类别，并结合样本进行解释。
- **训练过程分析**：报告中应展示训练集与验证集上的损失或评价指标变化，分析模型是否欠拟合、过拟合，以及采用了哪些训练改进措施。

### 七、实验报告要求

- **任务描述**：说明任务目标、输入输出形式、类别定义和数据来源。
- **数据分析与预处理**：包括数据规模、类别分布、清洗方法、切分方法、词表或编码方法、样本长度统计等。
- **模型设计说明**：描述所设计网络的整体思路、主要模块和选择理由。不要只贴代码，应说明为什么这样设计。
- **训练设置**：包括数据划分、损失函数、优化方法、训练轮数、批大小、随机种子、硬件环境等必要信息。
- **实验结果**：给出 Accuracy、Macro-F1、类别级结果、混淆矩阵或错误类型统计。至少包含一组对比实验，例如不同文本切分方式、不同模型结构、不同训练策略或不同超参数设置的比较。
- **结果分析**：分析模型优势、失败案例、类别混淆原因、训练技巧的效果，以及模型仍存在的问题。
- **心得体会**：总结在网络设计、训练调参、实验评测方面获得的经验。
- **学术诚信说明**：说明代码和报告是否独立完成，引用的开源代码、工具、数据或模型需明确标注来源。

### 九、评分标准

| 评分项目 | 分值 | 评分要点 |
| --- | --- | --- |
| 数据预处理与数据分析 | 20 分 | 能正确读取数据、完成清洗、切分、词表或编码处理，并给出类别分布和样本长度等基本统计。 |
| 模型设计与训练实现 | 30 分 | 能独立设计符合要求的 RNN + Attention 或 Transformer 模型，完成训练流程，并体现对网络结构和训练过程的理解。 |
| 实验评测与结果分析 | 25 分 | 能使用 Accuracy、Macro-F1、混淆矩阵等指标进行规范评测，包含合理对比实验，并能对结果进行有依据的分析。 |
| 实验报告质量 | 25 分 | 报告结构完整、表述清楚、图表规范，能够说明方法、实验设置、结果和心得体会。 |
