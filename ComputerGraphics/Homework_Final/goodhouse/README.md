# Good House
> 好房子项目
## Quick Start

### 运行

#### 运行`run.py`启动项目

运行后会启动程序后，会自动跳转到浏览器[goodhouse界面](http://localhost:8000/goodhouse.html)

```bash
python run.py
```

#### 其他启动方式

直接使用Python内置的HTTP服务器启动，运行后访问`http://localhost:8000/goodhouse.html` 

[点击访问goodhouse界面](http://localhost:8000/goodhouse.html)

```bash
python -m http.server 8000
```

> 如果不是python，也许是python3等其他名字

### 导入场景

- 点击右上角`导入场景`按钮
- 选择`import_scene`文件夹下的场景文件`scene_transforms_v11`进行导入
